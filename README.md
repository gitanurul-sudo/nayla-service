# nayla-service
Sistem manajemen layanan perbaikan perangkat elektronik berbasis Laravel dengan fitur konsultasi, tracking servis, dashboard admin, dan dashboard teknisi.

Nayla Service adalah aplikasi manajemen layanan servis perangkat elektronik berbasis Laravel.

## Fitur

### Customer
- Beranda
- Layanan
- Konsultasi
- Tracking Status Servis
- Lokasi

### Admin
- Dashboard
- Manajemen Pesanan
- Update Status Servis
- Manajemen Pelanggan
- Laporan

### Teknisi
- Dashboard Teknisi
- Daftar Pekerjaan
- Update Progress Servis
- Riwayat Servis

## Teknologi

- Laravel
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Vite
