# Nayla Service

Sistem manajemen layanan perbaikan perangkat elektronik berbasis Laravel dengan fitur konsultasi, tracking servis, dashboard admin, dan dashboard teknisi.

Nayla Service merupakan aplikasi berbasis web yang membantu proses pengelolaan layanan servis perangkat elektronik mulai dari konsultasi pelanggan hingga monitoring proses perbaikan.

## Fitur

### Customer
- Beranda
- Layanan Servis
- Konsultasi
- Tracking Status Servis
- Lokasi

### Admin
- Dashboard Admin
- Manajemen Pesanan
- Update Status Servis
- Manajemen Pelanggan
- Laporan

### Teknisi
- Dashboard Teknisi
- Daftar Pekerjaan Servis
- Update Progress Perbaikan
- Riwayat Servis

## Teknologi

- Laravel
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Vite
